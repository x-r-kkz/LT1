# CIRCULAR GARDEN CALCULATOR

## Description
The program aims to help the user calculate some of the measurements of a circular garden.
This program uses the math library and an inputted radius to calculate the
- Area (`math.pi * math.pow(radius, 2)`)
- Circumference (`2 * math.pi * radius`)
- Square root of the area (`math.sqrt(area)`)
- Area rounded down (`math.floor(area)`) &
- Area rounded up (`math.ceil(area)`)

of the circular garden.

## How to Run
- Go to the "*LT1"* repository.
- Click on *"CircularGarden.py"*.
- Download the file by clicking on the 3 dots on the upper right of your screen and pressing *"Download"*.
- Open the *"CircularGarden.py"* file.
- Run by pressing the triangular play button.

## Inputs Required
- Float number radius

## Sample Output

When input is 5:

*Area: 78.54 square meters*

*Circumference: 31.42 meters*

*Square root of the area: 8.86*

*Area rounded down: 78 square meters*

*Area rounded up: 79 square meters*
